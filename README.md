# 3550-JWKS-Server

- Jason Uzoukwu (jiu0009)
- CSCE 3550.001 (Foundations in Cybersecurity)

## PART 1: JWKS Server

A RESTful JWKS server that generates public keys and issues them via JWTs. It utilizes unique identifiers and timestamps for enhanced security and authentication of for JWT issuance.

## PART 2: SQLite Database

Extended JWKS server to store and read private keys from SQL database. It also handles user authentication by issuing valid and expired JWTs based on the users request.
